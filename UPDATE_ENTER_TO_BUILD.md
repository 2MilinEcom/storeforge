# StoreForge 0.7.1 — Enter to Build

This patch makes the primary Product / TikTok Shop URL field explicitly submit the autonomous build when you press Enter.

## Apply over your existing StoreForge folder

1. Stop the dev server with Ctrl+C.
2. From your StoreForge folder, unzip the cumulative update over the current files.
3. Restart StoreForge.

No `.env.local` or project data is included in the update, so your credentials and local data are preserved.
